## Known issues / notes for next session

### 1. Sub-agent Write permissions
Sub-agents in this project have Write and Bash denied. Write all files directly in the main session. Sub-agents work for research/read-only exploration only.

### 2. `.claude/` is gitignored
Skills, PROJECT_CONTEXT.md, and README changes are local only. Expected.

### 3. ajv caching (resolved — do not change)
Validator compiles schemas once at module load. Do not instantiate Ajv per call.

### 4. Path frequencies (resolved)
Validator does NOT flag frequency sums > 1.0. Paths can overlap. Already handled.

### 5. Schema enum values (learned from Task 3.5)
Key values to know when creating example files:
- `serviceModel`: `"self_service"` | `"managed"` | `"both"` (NOT "self-service", "assisted")
- `edgeType`: `"default"` | `"conditional"` | `"error"` | `"timeout"` | `"escalation"` | `"loop_back"` (NOT "sequential", "loop")
- `pathType`: `"designed"` | `"observed"` | `"simulated"` | `"failure"` | `"edge_case"` (NOT "exception")
- `provenance.researchSources[].type`: `"interview"` | `"survey"` | `"analytics"` | `"observation"` | `"existing_research"` | `"ai_synthesis"` (NOT "document")
- `provenance.generationMethod`: `"human_created"` | `"ai_assisted"` | `"ai_generated"` | `"mixed"` (NOT "designed")
- `emotions.intensity` and `momentThatMatters.emotionalIntensity`: integer -2 to 2
- `outcome.netSentiment`: integer -2 to 2 (NOT a string like "positive")
- Lane `id` must match `^[a-z][a-z0-9_-]*$` — use `need-at-step` and `pain-at-step` (NOT camelCase)

### 6. WS6 pattern-specialist change
v2.0 patterns are Markdown documents in `v2.0/patterns/` (not JSON artifacts). The skill documents them as Mission sub-graph templates. No schema validation needed for patterns themselves.

### 7. Claude Manager skills location
`tools/claude-manager/skills/` is **NOT** gitignored — these are tracked in git, unlike `.claude/skills/`. Normal Edit/Write operations apply.
