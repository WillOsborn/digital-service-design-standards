### BACK-017: AI Provenance & Generation Metadata
- **Category:** schema
- **Added:** 2026-05-04
- **Source:** research (Plan A — backward-compatible improvements)
- **Priority:** P1
- **Description:** Add optional `provenance` object to all artifact schemas (persona, role, pairing, journey, pattern) to support EU AI Act transparency requirements (Aug 2026 deadline). Fields: generation_method, ai_tools_used, human_reviewed, human_reviewed_date, data_sources_consent. Purely additive — no existing fields change.

### BACK-018: Privacy & Data Governance Metadata
- **Category:** schema
- **Added:** 2026-05-04
- **Source:** research (Plan A — backward-compatible improvements)
- **Priority:** P1
- **Description:** Add optional `data_governance` object to all artifact schemas for regulated environments. Fields: data_classification, contains_pii, pii_categories, anonymisation_method, retention_policy, legal_basis, data_owner. Driven by GDPR Digital Omnibus Package (Nov 2025). Small teams ignore it; enterprise teams opt in.

### BACK-019: AI Agent Representation in Journeys
- **Category:** schema
- **Added:** 2026-05-04
- **Source:** research (Plan A — backward-compatible improvements), elevates BACK-003
- **Priority:** P1
- **Description:** Add AI agent support to journey schema: (1) `agents` array in journey context declaring AI participants, (2) `actor` and `handoff` fields on steps for human/AI/hybrid/system actors, (3) `operated_by` on channels. Addresses 56% agentic support interaction projection (BCG 2025). Supersedes BACK-003.

### BACK-020: Expanded Accessibility & Cognitive Load
- **Category:** schema
- **Added:** 2026-05-04
- **Source:** research (Plan A — backward-compatible improvements)
- **Priority:** P2
- **Description:** Add (1) optional `accessibilityNeeds` object to Core Persona's behavioural_attributes with physical, cognitive, sensory, assistive_technologies arrays, and (2) optional `cognitive_load` object on journey steps with decision_complexity, information_density, time_pressure. Aligned with WCAG 3.0 expanded cognitive accessibility outcomes.

### BACK-021: Adaptive Journey Primitives
- **Category:** schema
- **Added:** 2026-05-04
- **Source:** research (Plan A — backward-compatible improvements)
- **Priority:** P2
- **Description:** Add optional fields for non-linear journeys: (1) `journey_type` enum (linear/adaptive/orchestrated), (2) `signals` array for external inputs, (3) `decision_point` on steps for conditional branching, (4) `sla` on steps for service level targets. Existing journeys implicitly `linear`. Supports journey orchestration platform integration.

### BACK-022: MCP-Compatible Annotations
- **Category:** schema
- **Added:** 2026-05-04
- **Source:** research (Plan A — backward-compatible improvements)
- **Priority:** P2
- **Description:** Add optional `annotations` object to all artifact schemas following MCP conventions. Fields: audience, usage_hints, related_artifacts, tags. Makes artifacts self-describing for AI tools and enables automated discovery, filtering, and relationship mapping.

### BACK-023: Structured Emotion Model
- **Category:** documentation
- **Added:** 2026-05-04
- **Source:** research (Plan A — backward-compatible improvements)
- **Priority:** P3
- **Description:** Document a recommended structure for emotion lane content supporting three models: simple (existing -2 to +2 scale, default), dimensional (valence-arousal), and categorical (Plutchik primary emotions). No schema changes required — lane_content already uses additionalProperties: true. Convention and tooling guidance only.

### BACK-024: JSON-LD Context
- **Category:** schema
- **Added:** 2026-05-04
- **Source:** research (Plan A — backward-compatible improvements)
- **Priority:** P3
- **Description:** Add optional `@context` and `@type` to all artifact schemas, plus optional `sameAs` on identity objects. Positions schemas as a potential UX research interchange standard. JSON-LD fields are ignored by standard JSON parsers. Requires publishing a context document. Recommend file extension conventions: .persona.json, .journey.json, .role.json, .pairing.json.
